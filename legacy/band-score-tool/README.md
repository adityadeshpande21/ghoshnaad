# Band score tool (from the ghosh-notation project)

The band-score page (`band.html`, built into `ghosh-band.html` by `assemble.js`), a standalone test player (`player.html`,
`ghosh-player.html`) and the PDF export (`export-pdf.js`). Kept as it was received, untouched and not part of the build or the tests.
It expects the layout of the old `ghosh-notation` repository (`src/timeline3.js`, `out/v3/`), so it will not run from here without that.
