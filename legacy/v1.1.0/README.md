# घोषनाद (Ghoshnaad)

घोष रचना · वादन · लेखन — an offline app for RSS Ghosh rachanas: 120 rachanas from the books, playback of every part, notation guide, sound check and घोषदंड संकेत.

**Open the app:** https://adityadeshpande21.github.io/ghoshnaad/

## Install on a phone
- **iPhone / iPad:** open the link in Safari → Share → *Add to Home Screen*.
- **Android:** open the link in Chrome → menu → *Install app* (or *Add to Home screen*).
- After the first open, the app works without internet.

## Use as a file
`Ghoshnaad.html` is the same app as one self-contained file. Download it and open it in Chrome, Edge, Firefox or Safari on a computer, or with Chrome on Android.

## What is in this repository (v1.1.0)
| File | Purpose |
| --- | --- |
